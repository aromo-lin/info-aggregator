# v1 端到端验收清单

> 手动验收。逐条执行，勾选即通过。失败项记录现象到「问题」区。

## 启动与骨架

- [ ] `npm run dev` 弹出 Electron 窗口，显示「项目 / 运行 / 设置」三个标签页。
- [ ] 无空白白屏、无控制台报错。

## 分组 / 信息源 / 身份（项目 标签）

- [ ] 点「新建项目」，出现「新项目 1」。
- [ ] 选中该项目，填一个小红书搜索源：站点=小红书、类型=搜索、关键词=`时尚资讯`、
      条数=`10`、不勾「抓评论」。
- [ ] 点「添加信息源」，该源出现在「信息源」列表里。
- [ ] 「登录身份」区新建一个身份：名称=`我的小红书`、站点=小红书，列表里出现该身份。
- [ ] 关闭应用重新打开：分组 / 信息源 / 身份仍在（持久化生效）。

## 运行（运行 标签）

- [ ] 点「刷新」，列表出现刚建的信息源。
- [ ] 勾选该源，点「运行选中源」。
- [ ] 弹出可见的 Chromium 窗口，进入小红书登录 / 首页；按提示手动登录（或验证码）。
- [ ] 登录后自动搜索 → 翻页 → 点开卡片读正文/图片；「运行」区进度日志滚动。
- [ ] 运行结束，出现「报告」区，含图片、不含评论。
- [ ] 被风控拦截的单条被跳过，其余正常，进程不崩溃、不无限挂起。

## 去重续抓

- [ ] 对同一源再点一次「运行选中源」。
- [ ] 报告只含新内容（已抓项被跳过）；若无新内容，日志提示「无新内容」。

## AI 综述

### 模式②（API）
- [ ] 「设置」标签切到 API 模式，填模型与 key，点「保存 key」。
- [ ] 「运行」标签报告区切到 API 模式，触发综述生成，综述出现在报告顶部。

### 模式①（导出）
- [ ] 报告区导出 Markdown 包（Markdown + 图片目录）。
- [ ] 把外部 AI 的综述文字粘回报告顶部 textarea，报告仍完整（综述可有可无）。
